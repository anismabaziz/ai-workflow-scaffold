# Blog drafts

Keep project-related blog writing here, one `.md` file per post. Draft
in whatever order suits you; when a post is finished and published, move the
file out to wherever you keep your blog source.

Suggested file name: `<day>-<slug>.md`, where `<day>` is `YYYY-MM-DD`.

Template to start a draft:

```markdown
# Title

Status: draft

## The hook
Why does this project thing matter? What will a reader get out of this post?

## The story
- What problem were you solving?
- What did you try, what surprised you?
- What ended up working?

## The takeaway
What would you do differently? What should the reader steal?
```
