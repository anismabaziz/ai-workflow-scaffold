# Example draft: Why we moved our planning into the repo

Status: draft

## The hook

Every change starts as a conversation. The trick is getting that conversation
to leave a paper trail the next engineer can actually read.

## The story

- The team used to plan in a separate tracker, so the "why" behind a decision
  lived far from the code that implemented it.
- We started writing specs, tickets, and review notes as plain markdown files
  next to the code, following one template each.
- The rule that stuck: the artifact only counts if it follows the template and
  lives where the workflow says it lives.

## The takeaway

The scaffold enforces the format, not the thought. Steal the templates, adapt
the workflow, and keep everything in one place.
